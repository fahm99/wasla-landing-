# Wasla (وصلة) - منصة تعليمية

منصة تعليمية تربط بين الطلاب والمدربين في بيئة احترافية.

## 🌟 المميزات

- 📚 تعلم من أفضل المدربين
- 🎓 كورسات احترافية
- 📜 شهادات معتمدة
- 📊 متابعة التقدم بسهولة

## 🚀 التقنيات المستخدمة

- **Flutter** - إطار العمل الرئيسي
- **Supabase** - قاعدة البيانات والمصادقة
- **Google Fonts** - خطوط احترافية (Tajawal, Cairo, IBM Plex Sans Arabic)
- **Material Design 3** - تصميم حديث

## 🎨 الخطوط

يستخدم التطبيق خطوط احترافية من Google Fonts:
- **Tajawal**: للعناوين الكبيرة
- **Cairo**: للعناوين المتوسطة والأزرار
- **IBM Plex Sans Arabic**: للنصوص العادية

## 📦 التثبيت والتشغيل

```bash
# تثبيت المكتبات
flutter pub get

# تشغيل التطبيق
flutter run -d chrome

# بناء للويب
flutter build web --release
```

## 🔧 الإعدادات

قم بإنشاء ملف `.env` في المجلد الرئيسي:

```env
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_supabase_anon_key
```
